## Preservation constraints

Keep existing navigation and core API response fields, versioned migration `0001`, synthetic dataset and legacy import contracts. Add migration `0002` and a separate enterprise module rather than duplicating domain inventory/exposure. Existing 73 backend, 6 frontend and 6 browser tests remain regression checks. Add an isolated synthetic integration scenario rather than resetting user data. Live source interfaces, schemas, credentials and controlled OEM limits remain unknown.

## Integration layers

`Connector → immutable source version/document → parser → fact proposals → deterministic identity matching → engineering review → atomic canonical transaction → existing component/exposure/PM read models`.

Persistent jobs own bounded retrieval, checkpoints, retries, dead letters and metrics. Sensor mappings and exposure definitions are effective-dated and require engineering verification. External demo mode accepts synthetic sources only; real connection implementation belongs inside an approved internal environment.
